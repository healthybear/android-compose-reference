# Noto Sans SC

`NotoSansSC-Regular.otf` is the unmodified source font used to generate the
Wasm Demo resource at build time. Its name table identifies it as **Noto Sans
SC**, version 2.004.

```sh
python -m pip install fonttools
pnpm run build:demos
```
